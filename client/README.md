## Installation

### Clone Repository

```bash
git clone https://github.com/md0ayan123/EXCELLENCE-SCHOOL-PROJECT.git
```

### Install Frontend

```bash
cd client
npm install
```

### Install Backend

```bash
cd ../server
npm install
```

---

## Run Frontend

```bash
cd client
npm start
```

Runs on:

```
http://localhost:3000
```

---

## Run Backend

```bash
cd server
node server.js
```

or

```bash
npm start
```

Runs on:

```
http://localhost:5000
```
